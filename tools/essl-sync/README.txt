StartupTN HR - eSSL sync
========================
Sends new fingerprint punches from eTimeTrackLite to StartupTN HR every 30 seconds.
Outbound only. Reads punches, devices and staff codes/names. Changes nothing in eTimeTrackLite.

Install (once, about 3 minutes)
  1. Unzip this folder to the Desktop.
  2. Right-click Install.bat > Run as administrator > Yes.
     (Blue "Windows protected your PC" box: More info > Run anyway.)
  3. Paste the link key from StartupTN HR > Tech admin > Setup > Biometric. Press Enter.
  4. Wait for "DONE". Close the window. You can delete the Desktop folder afterwards.

Check later
  C:\ProgramData\StartupTN\essl-sync\Status.bat  (right-click > Run as administrator)

Remove
  C:\ProgramData\StartupTN\essl-sync\Uninstall.bat  (right-click > Run as administrator)
